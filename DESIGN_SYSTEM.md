# Editorial Design System

## Approved visual direction
**AB — Modern Editorial foundation with selected Illustrated Learning elements.**

Use a calm, professional editorial system suitable for educational and reference books. Illustration should clarify ideas rather than decorate every page.

## Series identity
- One common series identity across books.
- Subject-specific accent colours distinguish volumes.
- The first reference subject is Financial Markets, using a muted teal accent.
- Core palette: deep navy/ink, warm neutral paper/background tones, restrained grey text, and one subject accent.
- Avoid relying on colour alone to communicate meaning.

## Typography
- Use a highly readable body face with clear distinction between headings and body text.
- Establish a consistent hierarchy for book title, part, chapter, section, body, caption, note, quotation, and reference text.
- Keep line length and leading comfortable for extended reading.
- Use robust fonts available in the build environment and document licensing/provenance before bundling fonts.

## Layout components
- Cover and title page
- Copyright / publication information
- Contents
- Part and chapter openers
- Standard reading page
- Key concept / definition callout
- Worked example
- Figure and caption
- Table
- Summary / review questions
- References, glossary, and appendices

## PDF versus EPUB
PDF may use fixed page composition, running heads, folios, controlled page breaks, and carefully placed diagrams. EPUB must remain reflowable: avoid fixed page assumptions, tiny text, and layouts that require side-by-side columns.

## Canva handoff
Canva is used to create and refine visual assets. Export assets in suitable formats and dimensions, preserve editable originals in the Canva workspace, and commit approved exports plus source/licence notes to the relevant book repository. Never make Canva a required step for routine builds.
